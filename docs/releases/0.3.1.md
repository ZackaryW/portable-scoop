# Portscoop v0.3.1

This release expands portable manifest compatibility through generic operations.

- Recognized pre/post-install operations support renaming, package-local copies,
  directory creation and literal defaults while preserving saved data.
- Proven optional host-profile imports are skipped individually. Unknown or
  required unsupported operations still reject the manifest.
- Frozen download plans support checked filename fragments, paired checksums
  and extraction selectors, and inert EXE downloads.
- Managed readers support ZIP/nupkg, 7z, tar, tar.gz/tgz and gzip without invoking
  external extractors or installers.

The pinned Main/Extras audit accepts **2,517 of 4,148 entries (60.7%)**, up 891.
This measures full install preflight, not runtime-tested applications; it remains
387 entries short of the 70% goal. See [coverage](../manifest-coverage.md) and
[targeted VM qualification](../generic-qualification.md) for evidence and limits.

## Existing installations

The backend contract is now `portable-operations-v1.0`. Create a fresh Store from
the complete v0.3.1 distribution when an existing Store has an older backend.
Store self-update does not migrate that backend. Updating a Host does not update
its existing Stores. Preserve old Stores separately if their data is needed.

The tag triggers Windows validation and release packaging. Installer assets
become available only after that workflow successfully publishes the release.
