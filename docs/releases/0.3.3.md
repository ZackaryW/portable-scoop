# Portscoop v0.3.3

Host `psp self-update` now updates all reachable registered Stores, including their
managed backends. It checks Stores even when the Host is already current, updates
each identity once, and reports offline or invalid registrations separately.

Apps, shims, persisted data and Store identities remain in place. Status and
recovery work across registered Stores, with independent rollback for each Store.

## Upgrading from v0.3.2

Run these commands through your **Host** launcher:

```powershell
.\psp.exe self-update
.\psp.exe self-update --status
.\psp.exe --version
```

Wait until the Host update reports completion and the version is `0.3.3`, then run
`self-update` again to upgrade its registered Stores. The older Host updater only
updates itself; this second run uses the new Store maintenance behavior.

See [Updating Portscoop](../self-update.md) for scope, partial outcomes and recovery.
