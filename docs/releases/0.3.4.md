# Portscoop v0.3.4

New Stores now start with Main and their own managed Git and 7-Zip tools,
including the default Store created during Host setup. No separate Git or
7-Zip installation is needed.

Portable hook support now handles literal collections, configuration defaults,
resource copies and package cleanup. Supported NSIS installers can be extracted
without running the installer, enabling apps such as PotPlayer while preserving
existing settings during reinstall and upgrades.

## Upgrading

Run through your **Host** launcher so registered Stores receive the matching
backend and managed tools:

```powershell
.\psp.exe self-update
.\psp.exe self-update --status
.\psp.exe --version
```

Confirm completion and version `0.3.4`. If an older Host reports a Store update
failure, run `self-update` again through the updated Host to retry that Store.
Offline Stores must be connected before they can update.

After runtime maintenance, `psp env bootstrap` prepares a missing Main bucket in
an existing Store and checks its managed tools. Existing buckets, applications
and persisted data are preserved. Direct Store self-update cannot migrate an
older backend; use Host maintenance for this release.

See [Updating Portscoop](../self-update.md) and
[Managed Store tools](../managed-tools.md) for details.
