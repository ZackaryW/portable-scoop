# Portscoop v0.3.5

Package compatibility output now groups repeated hook actions into short,
indented summaries. Routine metadata and compiler bookkeeping no longer fill
the terminal, while skipped optional host-data imports remain visible.

For individual operation decisions, source lines and reasons, run:

```powershell
psp install potplayer --verbose
```

`--verbose` also works with `update`, `uninstall`, `reset` and `cleanup`.

Update through your Host launcher with `psp self-update`, then check
`psp self-update --status` for completion. The Host also updates reachable
registered Stores.
